# FilmFinder frontend

Future Next.js application. This directory is a placeholder; no Node.js
project is initialized yet.

## Planned stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion for React
- Lucide React

## Planned routes

```text
/           Letterboxd profile import
/discover   Swipe-based movie recommendations
```

Movie images will be loaded from the TMDB CDN. No images are downloaded or
stored by this repository.

The detailed visual direction is documented in `docs/frontend.md`.
